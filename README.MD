# Apollyon — Проект для геймификации обучения

Apollyon — Telegram-бот, который помогает геймифицировать процесс обучения: задания, награды (опыт, золото), прокачка персонажа и простая система инвентаря. Этот репозиторий содержит структуру проекта, ядро логики, интеграцию с базой данных и реализацию Telegram-бота.

## Краткое описание
Бот позволяет:
- Создавать и выполнять задания;
- Начислять опыт и золото за выполнение;
- Отслеживать прогресс персонажа (уровни/статистика);
В будущем:
- Покупать предметы и качать скилы за уровень
- Проходить подземелья с монстрами
- Выбор класса персонажа

## Как это работает — цикл обработки (flow)

1. Пользователь нажимает кнопку "Выполнить задачу".
2. MIDDLEWARE #1: logging.py
   - Логирует действие, например: "User 12345 pressed button complete_task_42".
3. MIDDLEWARE #2: database.py
   - Создаёт DB session и добавляет его в контекст.
4. MIDDLEWARE #3: user_check.py
   - Проверяет, зарегистрирован ли пользователь. Если нет — предлагает /start.
5. HANDLER (telegram_bot/handlers/tasks.py)
   - Парсит callback.data, получает task_id и вызывает core.tasks.complete_task(task_id, user_id).
6. CORE (core/tasks.py)
   - Высчитывает награду: exp, gold.
   - Проверяет, нужен ли level up.
   - Обновляет данные через database.crud: update_exp, update_gold, mark_task_completed.
7. DATABASE (database/crud.py)
   - Выполняет SQL-запросы и commit.
8. HANDLER отправляет пользователю ответ:
   - "✅ Задача выполнена! +50 опыта, +25 золота"

## Модели БД (текущая проектировка)
В планах / реализовано:
- User — информация о пользователе Telegram (id, username, date_joined).
- UserCharacter — игровые параметры (exp, level, gold, стрики и т.п.).
- Task — задания, их текст, награды, статус (завершено/активно).
- Inventory — (планируется) инвентарь пользователя.
- Item — (планируется) описание предметов.
